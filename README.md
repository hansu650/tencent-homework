# 鹅苗成长副本

在线体验：待部署后补充 Render / Vercel 链接

对应作业：腾讯 AI-HR 培训生线上实战营作业三「成长副本」30-60-90 学习路径设计器。

一句话定位：帮助 HR 为 AI Native 组织的新员工生成一份 30-60-90 天学习、协作与产出计划，让新人从“会用 AI”走向“能和 AI 协作共创”。

## Demo 亮点

- 多步生成器：一次只问一个问题，收集岗位、AI 基础、成长目标和导师风格。
- 30/60/90 成长副本：根据岗位动态生成入门、协作、产出三阶段路径。
- 导师验收卡：不只给新人任务，也给导师判断新人是否成长的检查标准。
- PDF / LaTeX 报告：报告页支持 LaTeX 源码下载，并提供浏览器打印保存 PDF fallback。
- 课程内容映射：创意型、分析型、沟通型、技术应用型 HR 自然嵌入报告。
- 腾讯文化映射：用户为本、科技向善、正直、进取、协作、创造融入路径设计。

## 页面结构

- `/`：首页，明确展示作业三和产品定位。
- `/setup`：5 步生成器，每一步只问一个问题。
- `/plan`：30/60/90 成长副本结果页，也是最适合截图的页面。
- `/checklist`：导师验收卡。
- `/report`：最终成长报告，支持下载 LaTeX 和打印保存 PDF。

## 部署说明

Render 部署建议：

```text
Build Command: npm install && npm run build
Start Command: npm run start
```

Node 版本建议使用 `22.x`。项目不依赖数据库，报告生成使用前端打印 PDF fallback 和服务端 LaTeX 字符串生成，适合直接部署。

## 1 分钟演示路径

1. 打开首页，说明这是作业三「成长副本」30-60-90 路径生成器。
2. 点击“开始生成成长副本”，进入 `/setup`。
3. 依次选择岗位、AI 基础、成长目标、导师风格。
4. 生成 `/plan`，展示三张 30/60/90 阶段卡片。
5. 进入 `/checklist`，说明 HR 也帮助导师知道如何验收。
6. 进入 `/report`，展示最终报告，并演示下载 LaTeX / 打印保存 PDF。

## 300 字提交说明

《鹅苗成长副本》对应腾讯 AI-HR 培训生线上实战营作业三「成长副本」30-60-90 学习路径设计器。作品聚焦 AI Native 组织中新人的成长节奏：新人不再只是熟悉制度和业务，而是要逐步掌握 AI 工具链、理解人机协同，并完成真实产出。Demo 以 HR 视角设计一个轻量生成器，通过岗位、AI 基础、成长目标和导师风格四类输入，自动生成 30 天入门副本、60 天协作副本和 90 天产出副本。每个阶段包含关键任务、交付物、导师检查点和 AI 工具建议，帮助新人和导师对齐同一份成长路径。作品的创新点包括副本化成长、导师验收卡和报告化沉淀：它把传统新人培养从普通清单变成可参与、可验收、可复盘的路径，并最终生成可下载的 LaTeX / PDF 报告。AI 在其中只负责辅助生成、整理和建议，不替代导师与 HR 对新人真实表现的判断，体现科技向善和正直原则。

## AI 边界说明

AI 只辅助生成学习路径、整理任务和建议检查点，不替代导师与 HR 对新人真实表现的判断。对新人的评价应基于任务、交付物、导师观察和本人复盘，而不是凭感觉贴标签。
